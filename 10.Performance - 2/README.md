### Задание 1

Составьте задание через утилиту `cron` на проверку объёма кеш-обновлений еженедельно.

Кеш-обновления — это обновления, которые остаются после выполнения `apt update`, `apt upgrade`.

```
# Зайти под суперпользователем:
sudo -i

# Запустить конфигурирование cron:
crontab -e

# Прописать внизу файла:
1 0 1 * 1 echo du -sch /var/cache/apt/archives/ > /root/cron.txt
```



### Задание 2

1. Запустите процесс копирования большого файла (1 Гб) на жёсткий диск.
2. Запустите команду `iostat`.
3. Запустите `iotop`.

Какие процессы влияют на данные команды?
```
iostat — информация о ядре, загруженности cpu, дисках.

iotop - top для дисков. Ориенттированться лучше по записи. Чтение может использовать кэш. iops - операции чтения/записи данных на диск. Операции чтения и записи выстраиваюбтся в очередь для доступа к диску. Ключевое здесь - задержки между этими операциями. Если фрагменты записи/чтения маленькие, то время операциий значительно увеличивается.
```
